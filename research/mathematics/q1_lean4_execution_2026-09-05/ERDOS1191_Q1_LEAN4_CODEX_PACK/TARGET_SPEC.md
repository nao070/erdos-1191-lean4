# Q1の固定仕様 / Target contract

**このファイルは命題仕様であり、証明ではありません。** 出典は Erdős Problems #1191 の第1問 [S1]。同ページの第2問、有限Sidon集合の最大サイズ、正の定数による上界とは区別します。

## 原命題

Aを正の整数からなる無限Sidon集合とし、実数xに対し C_A(x) = #{a ∈ A : 1 ≤ a ≤ x} と置きます。Q1は、すべてのそのようなAについて

    liminf_{x→∞} C_A(x) √(log(x)/x) = 0

が成立するか、という問題です。logは自然対数です。

Sidon条件は a,b,c,d ∈ A および a+b=c+d から (a=c かつ b=d) または (a=d かつ b=c) が従うことです。同じ元を2回使う和も含めます。自然数の0を含むライブラリ定義を使う場合は、正の整数への制限・有限個の元の除去の影響を証明して揃えます。

## 形式化しやすい候補

    ∀ A, Infinite(A) ∧ Sidon(A) ⇒
      ∀ ε ∈ ℝ, ε > 0 ⇒
        ∀ M ∈ ℕ, ∃ N ∈ ℕ,
          N ≥ max(M,2) ∧ C_A(N)^2 log(N) < ε N.

これは実装上の候補であり、原命題との同値性もLeanで証明します。Nの実数へのキャスト、集合の数え上げ、liminfの非負性と定義域、平方根と二乗の変換、εを二乗する際の取り替え、実数cutoffと整数cutoffの比較を省略しません。Leanの全域関数としてのlogや除算の0での振る舞いを、数論の漸近命題の代わりに利用してはいけません。

## 完全反証に必要なもの

    ∃ A, Infinite(A) ∧ Sidon(A) ∧
      ∃ ε > 0, ∃ M ≥ 2, ∀ N ≥ M,
        C_A(N)^2 log(N) ≥ ε N.

この条件から原Q1の否定が従うことも形式化します。有限集合、有限範囲の探索、limsupの正値、部分列だけの下界では足りません。εはそのAに依存して構いません。

## 成功と取り違えやすいもの

正の定数Cによる liminf ≤ C は0という目標ではありません。C143の有限fixtureの正値は、任意の履歴・rankに対する一様定理ではありません。固定窓の方法への反例はQ1の反例ではありません。Q1と同値な未証明補題を仮定してQ1を証明することも完成ではありません。

`Q1 ∨ ¬Q1` を古典論理で証明するだけでは、どちらが正しいかを解明していません。成果物は肯定または否定の一方を、正しい命題と証拠で確定する必要があります。

## 定理の意味の確認

最終定理に余分な引数・型クラス・構造体フィールドがないかを確認します。Sidonや無限性を満たす入力が存在しないような誤定義にしません。独立したchallenge moduleの意味を固定し、証明コードが使う記法やインスタンスで別の命題に変わらないようにします。補助的な基本例の検査は有用ですが、それ自体をQ1の証明として扱いません。
