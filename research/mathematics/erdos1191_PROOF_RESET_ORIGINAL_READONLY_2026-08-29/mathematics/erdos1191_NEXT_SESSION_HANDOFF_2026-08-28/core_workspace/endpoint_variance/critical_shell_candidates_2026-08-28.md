# Critical-envelope birth-shell candidates

**Date:** 2026-08-28 (Asia/Tokyo)  
**Purpose:** finite falsification only; no finite search below is evidence for an
asymptotic assertion.

## Exact setup

Let `A=(a_1<...<a_M)` be a normalized finite Golomb ruler.  Fix integers
`j0<=J` with `2^J<=M`, and put

\[
 m_j=2^j,\qquad A_j=(a_1,\ldots,a_{m_j}),\qquad
 N_j=a_{m_j}-a_1+1.
\]

Thus every pair in `A_j` is short modulo `N_j`.  For an edge
`p=(a_u,a_v)`, let

\[
 b(p)=\max(j_0,\lceil\log_2 v\rceil).
\]

For ordered edge-pairs `(p,q)`, their birth shell is
`b(p,q)=max(b(p),b(q))`.  With the exact cyclic-arc covariance `K_N`, define

\[
 Q_j(p,q)=\frac{K_{N_j}(p,q)}{N_jm_j^3},
\]

\[
 S_{s,J}=\sum_{b(p,q)=s}\sum_{j=s}^J Q_j(p,q),
 \qquad
 D_{s,J}=\sum_{\substack{b(p,p)=s}}
                 \sum_{j=s}^J Q_j(p,p),
 \qquad
 O_{s,J}=S_{s,J}-D_{s,J}.
\]

The shell partition is exact:

\[
 \mathcal F_{j_0,J}(A)
 =\sum_{j=j_0}^J\frac{\operatorname{Var}C_{N_j}(A_j)}{m_j^3}
 =\sum_{s=j_0}^J S_{s,J}.
\]

For a prescribed rational `C>0`, call the ruler **C-compatible** when every
tested dyadic prefix satisfies the critical envelope

\[
 N_j\le 2C m_j^2\log m_j.
\]

Because exact rational arithmetic cannot represent `log`, the tempting
rational surrogate

\[
 N_j\le 2C m_j^2 j
\]

(is looser, because `j <= log(2^j)=j log 2` is false).  Therefore this
surrogate is **not** used to certify compatibility with the analytic envelope.
The search records
the exact integer `N_j` and the symbolic threshold coefficient
`N_j/(2m_j^2)`, while a directed-rounding interval computation separately
certifies `N_j <= 2 C m_j^2 log(m_j)`.  No floating-point comparison decides
compatibility.

## Candidates to attack

All quantifiers below range only over rulers satisfying the critical envelope
at every tested dyadic prefix.

1. **H1 (off-diagonal birth negativity).**  For every `s<=J`,
   `O_{s,J}<=0`.

   Together with the already-proved absolutely summable diagonal estimate,
   H1 would make the whole critical functional bounded.

2. **H2 (shell diagonal domination).**  For every `s<=J`,
   `0<=S_{s,J}<=D_{s,J}`.

   This packages both absence of a negative net shell and the cancellation
   needed for the same boundedness conclusion.

3. **H3 (no future amplification).**  For every `s<J`,
   `S_{s,J}<=S_{s,s}`.

   This tests whether the tail of an interaction born at scale `s` can be
   discarded in an attempted scale-local estimate.

4. **H4 (scale-local diagonal domination).**  At every scale `s`, the
   ordered interactions born at `s`, evaluated only at `N_s`, have
   nonpositive off-diagonal sum.  Equivalently `S_{s,s}<=D_{s,s}`.

   H4 is weaker than H1 at horizon `J=s` only in notation, but it separates a
   local obstruction from one created by persistence through later moduli.

5. **H5 (critical-envelope level monotonicity).**  Writing
   `E_j=Var(C_{N_j}(A_j))/m_j^3`, one has `E_{j+1}<=E_j`.

   This is not by itself sufficient for the target `o(log J)` estimate.  It is
   tested because several possible averaging arguments tacitly require it.

6. **H6 (net-shell nonnegativity; refinement added after the first exhaustive
   pass).**  For every `s<=J`, `S_{s,J}>=0`.

   H2 mixes this lower inequality with the false upper inequality
   `S_{s,J}<=D_{s,J}`.  H6 separates the lower inequality because it survived
   the initial exhaustive ranges.  Survival is reported only as finite data;
   it is not promoted to a theorem.

The first counterexample is ordered lexicographically by
`(J, diameter, ruler, shell, horizon)`.  Exhaustive claims always name their
candidate denominator and accepted Golomb-ruler count.  Random searches record
their PRNG seed, construction rule, attempt count, and all retained witnesses.

## Independent checks

The implementation under test uses the four-endpoint kernel.  Its oracle uses
literal cyclic arc sets and direct crossing-load variances.  Certificate
generation fails if either

\[
 \sum_s S_{s,J}=\mathcal F_{j_0,J}
\]

or the kernel/oracle equality fails.  Expected values in unit tests are
hand-derived literals rather than values generated by the implementation.
